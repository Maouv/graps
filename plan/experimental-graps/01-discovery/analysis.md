# Analysis

> **Summary Block:** The viable architecture is structural-first with a validated semantic overlay. This separates deterministic topology from probabilistic naming and keeps the application useful during AI failure.

## JTBD
When examining an unfamiliar repository, a developer needs to navigate stable modules/files/functions and inspect supported call relationships so they can form an architecture model without trusting invented edges.

## Key insight
- Structural facts own identity, hierarchy, order, edges, and confidence.
- AI may improve names, summaries, responsibility, and capability metadata only.
- Fallback is not a degraded emergency screen; it is the fully functional structural product.

## Main uncertainty
Parser coverage and static call resolution differ by language. Python is first-class for MVP; other languages degrade explicitly rather than simulate certainty.
