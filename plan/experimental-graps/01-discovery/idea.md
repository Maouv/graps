# Idea

> **Summary Block:** Turn Graps into a local-first code architecture explorer that shows truthful structure and optional semantic context without making AI a runtime requirement.

## Problem
Current code exploration needs a coherent mapping from filesystem and parser facts to modules, source, and callable flows. AI-only interpretation is non-deterministic and can invent relationships.

## Intended outcome
A developer can identify what exists, open source, inspect structurally supported calls, and optionally see validated business labels.
